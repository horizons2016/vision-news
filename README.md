# رصد الرؤية — حراك أخبار رؤية عُمان 2040

يرصد الأخبار من المصادر العُمانية الرسمية والصحفية، ومما تنشره المصادر العالمية عن عُمان. يحتفظ فقط بالأخبار المرتبطة بأولويات الرؤية ومؤشراتها، ويصنّفها حسب **المحور ← الأولوية ← المؤشر** (القائمة المحدثة: 12 أولوية و38 مؤشرًا). ثم يُخرج تقارير أسبوعية وشهرية عن الحراك، وإشارات حراك لكل مؤشر.

الغرض:
1. **وعي فريق العمل** بما يحدث في كل أولوية.
2. **إشارة مبكرة** إلى المؤشرات التي يدور حولها نشاط إعلامي متصاعد أو متراجع. تُربط لاحقًا بداشبورد «مؤشرات الرؤية».

> الإشارة تقيس حجم التغطية الإعلامية، ولا تقيس أثرًا فعليًا على قيمة المؤشر.

---

## كيف يعمل

```
كل 3 ساعات (GitHub Actions — مجاني)
  1. collect.py  يسحب المصادر (RSS، وإن فشل يقرأ صفحة الأخبار) ← يصنّف بالقواعد ← يحفظ المرتبط فقط
  2. ai.py       (اختياري) يحسم الأخبار «المحتملة» إن أُضيف مفتاح ذكاء اصطناعي
  3. build.py    يطبّق قرارات الفريق ← يبني التقارير والإشارات ← يُنشر الموقع
```

| المجلد | المحتوى |
|---|---|
| `config/sources.json` | المصادر وروابطها |
| `taxonomy/` | المرجع الرسمي (`reference.json`) وقواعد التصنيف (`rules.json`) والمصنّف |
| `data/articles/` | الأرشيف، ملف لكل شهر |
| `data/decisions.csv` | قرارات الفريق (تأكيد، رفض، تعديل) |
| `data/state/` | حالة المصادر والروابط التي سبق رؤيتها |
| `reports/weekly`, `reports/monthly` | التقارير بصيغة Markdown، وتُقرأ مباشرة في GitHub |
| `site/` | الموقع، ويُثبَّت على الجوال والكمبيوتر كتطبيق |

**ما يُحفظ:** العنوان، ومقتطف قصير، ورابط المصدر، والتصنيف وسببه. لا يُعاد نشر نص الخبر.

## الإعداد لأول مرة (مرة واحدة)

1. في GitHub أنشئ مستودعًا جديدًا عامًا (Public) باسم `vision-news`.
2. ارفع كل محتوى هذا المجلد: **uploading an existing file** ← اسحب الملفات ← **Commit changes**.
   - **تنبيه:** المجلد `.github` يبدأ بنقطة، وقد يكون مخفيًا في جهازك فلا يُرتفع. تأكد أن الملف `.github/workflows/update.yml` ظهر في المستودع.
   - إن لم يظهر: **Add file ← Create new file**، واكتب الاسم `.github/workflows/update.yml`، والصق محتوى الملف `docs/نسخة-ملف-التشغيل-التلقائي.yml`.
3. **Settings ← Actions ← General ← Workflow permissions**: اختر **Read and write permissions** ثم Save.
4. **Settings ← Pages ← Source**: اختر **GitHub Actions**.
5. **Actions** ← «رصد وتحديث ونشر» ← **Run workflow**.
6. بعد 3 إلى 5 دقائق يصبح الموقع على `https://horizons2016.github.io/vision-news/`.

الأرشيف مُحمَّل مسبقًا بأخبار يوليو–نوفمبر 2026 من النظام السابق، بعد إعادة تصنيفها بالقواعد الرسمية. لذلك تظهر التقارير من اليوم الأول.

## بعد أول تشغيل: افحص المصادر

افتح صفحة **المصادر** في الموقع. لكل مصدر ترى:
- يعمل أو فشل.
- الطريقة المستخدمة: RSS أو قراءة الصفحة.
- سبب الفشل إن وُجد.

روابط RSS لبعض الصحف، مثل الوطن والرؤية والشبيبة ووكالة الأنباء، وُضعت كاحتمالات ولم يُتحقق منها. إن فشل مصدر:
1. افتح موقع الصحيفة وابحث عن رابط RSS. غالبًا يكون أسفل الصفحة أو على شكل `/feed` أو `/rss`.
2. افتح `config/sources.json` ← أيقونة القلم ✏️، وضع الرابط في أول قائمة `feeds` لذلك المصدر ← **Commit changes**.
3. إن لم يكن للصحيفة RSS، يقرأ النظام صفحتها الرئيسية. ويلزم أن يطابق `linkPattern` شكل روابط أخبارها. انسخ رابط خبر من الصحيفة وأرسله لمسؤول النظام لضبط النمط.

**إضافة مصدر جديد:** انسخ أحد المصادر في `sources.json`، وغيّر `id` والأسماء والروابط.
**إيقاف مصدر:** اجعل `"active": false`.

## عمل الفريق: المراجعة والقرارات

في صفحة **المراجعة** ثلاث قوائم:
- **بانتظار التأكيد:** أخبار ربطتها القواعد بأولوية، لكن فيها سبب يستدعي نظرة بشرية، ويظهر السبب تحت كل خبر. هذه لا تُحتسب في التقارير حتى تُؤكَّد.
- **محتملة:** أخبار عُمانية فيها إشارة لموضوع من مواضيع الرؤية دون حد الإثبات.
- **المستبعدة مؤخرًا:** للتأكد أن القواعد لا تُسقط أخبارًا مهمة.

لكل خبر ثلاثة أزرار: **تأكيد**، أو **تعديل الربط** (اختيار الأولوية والمؤشرات)، أو **غير مرتبط**. القرار يُحفظ مسودةً على جهازك. لتثبيته للجميع:
1. «المراجعة» ← «قراراتي» ← **نسخ الأسطر**.
2. في GitHub افتح `data/decisions.csv` ← ✏️ ← الصق الأسطر في آخر الملف ← **Commit changes**.
3. بعد دقائق يُعاد البناء تلقائيًا. احذف بعدها المسودات من التطبيق.

شكل السطر:
```
معرف الخبر,القرار,الأولوية,المؤشرات,بواسطة,ملاحظة
6ad8e52548d8,تعديل,P06,I19 I20,محمد,
a1b2c3d4e5f6,رفض,,,محمد,خبر بروتوكولي
```

- رموز الأولويات من P01 إلى P12، ورموز المؤشرات من I01 إلى I38، وتظهر في صفحة «الأولويات والمؤشرات».
- إن أخطأ أحد في رمز، مثل مؤشر لا يتبع الأولوية، **يتوقف النشر** ويظهر السبب بالعربية في صفحة Summary للتشغيل. ويبقى الموقع كما هو.

## تفعيل الذكاء الاصطناعي (اختياري)

بدونه يعمل كل شيء، وتبقى الأخبار «المحتملة» بانتظار الفريق. لتفعيله:
1. احصل على مفتاح API من Anthropic أو OpenAI. الاستخدام مدفوع لكنه بسيط: نحو 40 خبرًا في التشغيلة، في دفعات من 10.
2. **Settings ← Secrets and variables ← Actions ← New repository secret**.
3. الاسم `ANTHROPIC_API_KEY` (أو `OPENAI_API_KEY`)، والقيمة هي المفتاح.
4. اختياري، من تبويب **Variables**:
   - `AI_MODEL` لتغيير النموذج.
   - `AI_MAX_ITEMS` لتغيير الحد في التشغيلة.

**ما يُرسل:** العنوان والمقتطف القصير فقط.

**القرار:**
- ثقة 75% فأكثر: يُعتمد الخبر تلقائيًا.
- ثقة بين 50% و75%: يُحال للتأكيد مع اقتراح الذكاء الاصطناعي.
- غير مرتبط: يُستبعد.

الأخبار المحتملة في الأرشيف (نحو 2,100) تُعالَج تدريجيًا، الأحدث أولًا.

## الربط مع داشبورد «مؤشرات الرؤية»

- افتح `config/indicator_links.csv`، واكتب في العمود الثالث رمز كل مؤشر كما هو في داشبورد المؤشرات (مثل `U-31`).
- يظهر الرمز بعدها في صفحة «الأولويات والمؤشرات» كرابط للداشبورد.
- رابط الداشبورد في `config/settings.json`.

**مستقبلًا:** يستطيع داشبورد المؤشرات أن يقرأ ملف `data/meta.json` المنشور من هذا الموقع، ففيه `signals` وهي إشارة الحراك لكل مؤشر. فيعرض بجانب كل مؤشر: «حراك إعلامي متصاعد: 6 أخبار في 4 أسابيع».

## منهجية التصنيف (مختصر)

1. **سياق عماني:** ذكر عُمان أو محافظاتها أو مؤسساتها، أو أن الخبر من صحيفة عمانية ولا يذكر بلدًا آخر في عنوانه.
2. **الأولوية:** مصطلحات لكل أولوية، وللعنوان وزن مضاعف. تُثبت الأولوية بثلاث نقاط فأكثر.
3. **المؤشر:** بدليل مباشر فقط، مثل اسم المؤشر أو مصطلح يحرّكه مباشرة.
4. **الاستبعاد:** الرياضة والطقس والحوادث والتعازي والأخبار الخارجية.

**تعديل المصطلحات:**
- عدّل `taxonomy/rules.json`، ثم ارفع رقم `version`.
- الاختبارات في `tests/` تعمل تلقائيًا قبل كل نشر، فإن كسر التعديل شيئًا يتوقف النشر.

**لإعادة تصنيف الأرشيف كله بعد تعديل القواعد:**
```
python scripts/reclassify.py
```
يعتمد على العنوان والمقتطف المحفوظين. ولا يمس قرارات الفريق ولا ما حسمه الذكاء الاصطناعي.

## التشغيل على جهازك (اختياري)
```
pip install -r requirements.txt
python scripts/collect.py      # جمع
python scripts/build.py        # بناء
cd site && python -m http.server
```
ثم افتح `http://localhost:8000`.

## الخصوصية

- المستودع العام يجعل الأرشيف والقرارات وأسماء من اتخذها مرئية لمن يفتح المستودع.
- الأخبار نفسها منشورة أصلًا. أما إن كانت قرارات الفريق أو ملاحظاته داخلية، فالبديل مستودع خاص بخطة GitHub مدفوعة، أو خادم داخلي في الوزارة.
